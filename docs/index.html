🚀 Run It Yourself

# Clone and install
git clone https://github.com/MPParsley/hello-finetuning
cd hello-finetuning
pip install -r requirements.txt

# Fine-tune
python src/train.py

# Compare base vs fine-tuned
python src/inference.py

# Build the report
python src/generate_report.py
open docs/index.html
